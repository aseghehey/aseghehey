# Emanuel Aseghehey

**Distributed systems · cloud infrastructure · developer tooling**

I'm a software engineer at AWS. I like control-plane problems: capacity and scaling, workflows that recover cleanly when something fails halfway, and the tests and tooling that make that kind of change safe to ship.

Outside of work, I contribute to open-source AWS emulation and build small tools that make my day-to-day development faster.

## Open source

- **[Floci](https://github.com/floci-io/floci)** — an open-source AWS emulator. I contribute through [Andre Kurait's fork](https://github.com/AndreKurait/floci), mostly on EC2 networking, IAM and KMS authorization, and making services behave locally the way they do on real AWS. [My merged pull requests](https://github.com/AndreKurait/floci/pulls?q=is%3Apr+is%3Amerged+author%3Aaseghehey).
- **[OpenSearch Benchmark workloads](https://github.com/opensearch-project/opensearch-benchmark-workloads/pull/334)** — added vector search parameters.

## Some things I've built

- **[encontra](https://github.com/aseghehey/encontra)** — a Rust CLI for full-text search over Claude Code session logs.
- **[sheepy](https://github.com/aseghehey/sheepy)** — a Tauri app that shows Claude Code sessions running in [Herdr](https://herdr.dev) terminals as live chats.
- **[herdr-chat](https://github.com/aseghehey/herdr-chat)** — a chat window for Herdr that sits over Claude Code and Codex agents.
